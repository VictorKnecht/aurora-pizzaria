# Aurora Pizzaria — projeto demonstrativo da ALVORA

Site estático feito com HTML, CSS e JavaScript puro.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Antes de apresentar como projeto comercial
- Troque o WhatsApp de demonstração `5546999999999` pelo número autorizado do estabelecimento.
- Atualize nome, preços, endereço, horário e textos conforme o cliente real.
- As imagens usam URLs do Unsplash e precisam de conexão com a internet.
- Este é um projeto fictício de portfólio; não representa um restaurante real.

## Publicar no Cloudflare Pages
Crie um repositório separado para este projeto, envie o conteúdo desta pasta para a raiz do repositório e conecte-o ao Cloudflare Pages.
Como é HTML/CSS/JS puro, deixe o comando de build vazio e use `.` como diretório de saída.
